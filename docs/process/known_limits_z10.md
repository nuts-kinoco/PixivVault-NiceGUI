# FL-Z10（通信レーン）受入時の既知の限界（2026-11-19、Sonnet 判断、Sol 第12回・Argon 監査を経て）
- 実装: request_policy.RequestAdmission（元 rate_coordinator.py と同じ予約方式＋実発行間隔の確認）。レーン: interactive（学習の現在作品・概要取り直し・発掘フォロー新着・発掘ランキング・ランキング画面（通常/小説）・フォロー/ブックマークの CSRF 前段）、background（それ以外）。ライブラリの pixiv 検索は借用経路で共有ゲートを通らないため未接続。
- 既知の限界（所見）: (a) 設定変更直後の 1 件が旧間隔で通ることがある、(b) 設定ストアのロック保持中は取消が即座に返らない、(c) 画集ビューアのページ一覧は元で background だが現在表示と共通経路のため interactive、(d) ゲート通過から送信までの遅れ、(e) 起床順がミリ秒単位で入れ替わる極端なタイミングで、実発行間隔の補正により先に予約した要求が後続に抜かれて期限切れになる／期限内に通れない要求が枠を取る（Sol 第12回 中 2 件）。
