# FL-Z01/Z02（作者 ZIP）受入時の既知の限界（2026-11-19、Sonnet 判断、Sol 独立検証 5 回を経て）
- ZIP は管理領域から再生成できる派生物。管理領域が正で、元データは失われない。
- 題名が他作品と衝突し、かつ画像のバイト列が同一という組み合わせで、隔離・復元の ZIP への反映が不完全になりうる（Sol 第 5 回: 別作品の隔離で既存画像が ZIP から消える／隔離ページが ZIP に残る）。重大度は medium とした（データ喪失ではないため）。
- use_work_folder=1 の作品別フォルダ・元 URL ファイル名の出力は未実装（managed_downloads.py の変更が要る。wt-w の統合後に実施）。
- 物理 ZIP の ZIP64 選択は 4000 MiB 境界（Python の ZIP32 ガードは約 2 GiB）。
