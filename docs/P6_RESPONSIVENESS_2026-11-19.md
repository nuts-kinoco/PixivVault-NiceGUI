## D7 安全

`tools/p6_network.py` は `src` の候補を AST とブラウザ資産のパターンから抽出し、コードの指紋と `tools/p6_network_review.json` の経路判定を照合する。新規・変更・未分類・迂回を失敗にする。272 箇所を列挙し、ゲート経由 161、ローカル 24、手動リンク 7、通信を伴わない設定・能力確認 42。未経由 9、経由と迂回の両方から到達する箇所 29。独立した静的レビューで、公開 CDN と Shaft の迂回、借用検索・ランキングからのアカウント更新経路を照合した。ゲート本体、関数を引数として渡す呼び出し、ブラウザの画像 URL 割り当ての指摘を検査へ反映した。実行時に組み立てる任意コードの解析まで保証する方式ではない。

- 借用アカウントのバックグラウンド keeper と借用検索・ランキングは、Shaft の ACCOUNT・ONLINE 等へ共有ゲートの外から到達する。`external_vault_transport.py` の `_request` は直接 Pixiv API・OAuth と Shaft 側の経路を分けている。
- `services.py` は借用画像用の `PublicImageReadClient` を作り、予算制限と再試行を設定する。`bind_public_cdn_shared_stop` を呼ぶ製品経路がこの候補にない。
- C ドライブは試験前 2,264,344、試験後 2,291,728 ファイルを列挙した。うちユーザープロファイル以下は前 1,540,274、後 1,567,657。`nat/AppData` は前 711,774、後 739,119。追加パスは 27,450 件。事後にパス接頭辞を照合し、並行動作中の EMA の一時領域 27,310 件、他アプリの管理領域 107 件、Windows の保守ログ 2 件を分類した。31 件は帰属未確認。列挙エラーは前 41,752 件、後 41,759 件で、各 41,687 件がアクセス拒否。取得できた範囲の前後差分として記録し、C ドライブへの新規作成なしの判定は保留する。
- 機密パターン検査は、共有 Git オブジェクトストア内の 657 コミットと 2,910 blob、ログ・STATUS・証拠の 258 ファイルを走査した。検出はトークン 162、開発パスワード 8、Cookie 6 で、176 件すべて Git 上。試験出力の直接監視と証拠ファイルの走査では 0 件。1 件の長いパスで発生した列挙エラーは Windows の拡張パスで再走査し、対象の証拠ファイルは 0 件だった。検出値は出力しておらず、176 件は実資格情報かどうかの判定前の箇所数。
