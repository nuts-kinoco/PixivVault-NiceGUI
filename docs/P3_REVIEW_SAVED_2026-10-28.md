# D15 振り返りの保存済み表示 — CoS 引継ぎ

基準: 固定254 `p3-capacity-lease-20261028`、HEAD 2cf4a7a7286dd728e8df8125094498a3622babba、集合 SHA 0ee63c9f234587ece5e1f872ec1afc776383ea2b3d59b06882c82d1a3fa88c15。実装担当は試験・アプリ起動を実行していません。

受付後にJobServiceの終端状態を検知し、既存の review_snapshot を再取得します。保存済みの判断はその snapshot が返す検証済み保存情報に従い、done/受付だけから作りません。error/stopped は状態を説明し、失敗リストからの明示Retryを保持します。未保存フィルタ・再訪時は同じ snapshot を使用し、閉鎖や再訪をまたぐ古い応答を捨てます。表示更新中の判定取消は保留します。

CoSは隔離合成ルート・実通信なしで以下を一括確認してください。

1. `pytest -q tests/test_p3_review_saved.py tests/test_learning_review.py tests/test_p3_residuals_fixtures.py` を実行し、既存fixtureの要件（CPU codec等）は結果とSKIP理由を記録する。
2. 合成発掘候補を2作品以上判定して振り返りを開き、未保存を示すことを確認。1作品を通常の保存ボタンで受付し、完了前は保存済みにならないこと、ジョブ完了・実receipt検証後にその作品のみ保存済みで無効となること、未保存フィルタでその作品のみ消えることを確認する。
3. 合成失敗および停止で保存済み表示にならず、失敗リストからの明示Retry後にreceiptが確認された場合のみ保存済みになること。receipt照合失敗時は確認エラーを表示し誤表示しないこと。
4. 振り返りを閉じる・タブ移動・再訪・再起動で、既存のreceiptから保存状態が復元されること、遅延応答で別セッションの画面が書換わらないこと。2作品のID取り違えがないことを確認。
5. 静止画とうごイラ両経路の対象ジョブ、ライブラリの実receiptと画面、関連consoleエラー、所有process終了を記録する。短命の大量ジョブによる表示窓からの退避は未検証であり、再訪時のsnapshot再照合を確認する。

L12やP3全体の受入、独立監査、実API/実データの検証は対象外。以前の試験結果をこの候補の新規検証として継承しない。
