# 合成ライブラリの作者・ページ閲覧：実装と受入

2026-10-22。基準は main `6d2046f4d6793340923661650b3e9cd2e29df35e` (PR #8 マージ後)。対象は別worktree `phase4/library-author-pages` の**合成DL済みライブラリ**に限定する。原版の本番DB・保存画像・ZIP/フォルダ・Cookie・pixiv APIには接続しない。

## 受け入れた最小経路

- ライブラリタブを有効化し、既存の固定8タブとランキング・学習の動作を保った。
- `author_id` 単位で全作品を集約。同じ表示名でも別IDは別作者として扱い、作者が1作品でも検索一致すれば作者カードを残す。代表画像は**検索前の全作品**から最後の保存日が最も新しい作品を選ぶ。未計測容量は未計測と表示する。
- 作者詳細はその作者の**全作品**を保存日降順、各作品内ページ昇順で展開する。検索で絞られたページだけを表示する誤実装を避け、詳細ヘッダーに作者の作品数・総ページ数・絞り込みの適用範囲を明示。
- ページ数が不明な作品は便宜的に1枚だけ並べ、`known=False` の属性を保ち注記する。原版の1始まり表示と画像APIの0始まりページ番号は `PageRef` の境界で変換。
- 最初は50ページ、明示「もっと見る」で50件ずつ追加する。追加前のカードDOMと内部スクロールを維持。作者一覧へ戻り再入場すると50ページから再開するが、作者一覧の検索・ソートは維持する。
- 同一クライアントではランキングとライブラリの大/中/小カードサイズが同期し、タブ往復で作者詳細・展開数・カードDOMを維持する。別クライアント間では検索・選択・表示数・カードサイズを共有しない。
- 共有ビューア部品を再利用し、選んだページから開く。画像表示時に実decode・新しい要求世代を検査し、古い画像通知・古いカードクリック、タブ離脱後の通知や非表示タブの遅れた入力を拒否。閉じると元カードへフォーカス復帰。リトライ操作は合成HTTP故障で確認する。
- 読取失敗と該当0件を別表示し、再読込操作を用意した。起動時のサービスは合成fixtureのみで、既定の本番DB接続はない。
