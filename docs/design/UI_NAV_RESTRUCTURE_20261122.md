Flet の画面順とランキング 2 画面の隣接を保つ。 `tab-bookmarks` を加え、主ナビの `tab-scheduler`／`tab-metadata` は `automation-open` とダイアログ内の選択先に移す。 `history` は起動互換とヘッダー操作のため維持する。**製品では全ラベル＋Material アイコン**を等幅で表示する。ワイヤーフレームの記号は配置の見本。カスタムランキングの内部キー `personal`、セレクター、設定キーは維持する。 `aria-current=page` は背後の選択中タブだけに付け、主ナビは Tab／Enter／Space で到達・操作できるようにする。主ナビの roving tabindex は将来課題。キュー・失敗リスト・学習の役割はツールチップと初回の説明で補い、追加の見出し行は設けない。制限付き起動には従来の利用条件と理由を適用する。

最上段に赤い本番 DB 警告を置き、通常文は 28 px を予算とする。641 CSS px 以上の長文は全文を折り返し、追加行を予算に足す。640 CSS px 以下では本番 DB の使用と保存先を要約に常設し、640×400 の試験条件で 1 行に収める。モックの長い保存先はルート名と末尾を表示し、省略を「…」で明示する。「詳細」で保存先の完全な表記と警告全文を開き、Esc または「閉じる」で入口にフォーカスを戻す。ロゴ、ログイン状態、API 切り替えスイッチ、「取得停止の確認・回復」ボタンと取得状態を置く。右上は「バックアップ履歴 → 閲覧履歴 → 保存先 → テーマ → Web → 設定 → 自動処理」。7 個を 40 px、間隔 4 px とすると 304 px。バッジは自動処理アイコンに重ね、未解消の失敗件数を同じヘッダーに置く。状態行はヘッダー直下。狭幅では操作列を次行へ流しても、本番 DB 警告、保存先、取得停止の入口と未解消件数は常時見える位置に置く。アイコンにはツールチップとアクセシブル名を付ける。

標準倍率は OS 100% 相当。1280 CSS px 以上は等幅 10×1。641〜1159 CSS px は等幅 5×2 とし、1280×800 の 125%（実効 1024×640）が該当する。1280 で行を増やさず全ラベルを収めるため、ワイヤーフレームでは幅に応じてアイコンと文字を上下に置く。FL-V03 の 1280px の 2 段裁定から 1 段へ移すには、製品のフォント・Material アイコン・フォーカス枠・操作域が全て収まる計測証拠が条件。条件未達なら 1280px でも等幅 5×2 に戻せる。比較時は警告の各行、ステータス、ツールバーをすべて高さに含める。

640 CSS px 以下では「現在の画面名 ／ 全画面の一覧を開く」のボタンから 10 画面を開く。DB 警告と保存先、取得停止の入口、未解消件数はナビが閉じていても表示する。開いた一覧は本文上に重ね、Tab で各画面へ進み、Enter／Space で選ぶと閉じる。選択先の作品、または画面の見出しへフォーカスを移す。Tab／Shift+Tab で開閉ボタンを含むナビ領域から出たら閉じ、移動先のフォーカスを保つ。開いている間の Escape は、ナビ内外のどこにフォーカスがあっても閉じて開閉ボタンへ戻す。IME 変換中の Escape はそのまま処理する。

**N1 の試験。** 固定 640×400 CSS px と 1280×800 相当のページズーム 200% の両方で、通常と併発を試す。入口から Tab で 10 項目を順に通り、「おすすめ」の次に本文の「取得・更新」へ移る。逆向きは先頭項目から開閉ボタンを経てヘッダーに戻る。ナビの項目、開閉ボタン、領域外にフォーカスを置いた開状態でそれぞれ Esc を押す。各移動直後にフォーカス、`aria-expanded`、ナビの開閉、`elementFromPoint` でフォーカス要素の中心が最前面にあることを照合する。正方向でナビが閉じた直後に Esc を押しても、本文のフォーカスを保つ。

### マイブックマーク

- 初回訪問に既存の `BookmarkView` を一度だけ生成して保持する。ライブラリの旧切替を外し、DL済みの作者一覧 → 作品一覧 → 戻るはそのまま辿れる。ライブラリの初期描画がブックマークを生成・更新する依存も切る。入口はタブに一本化する。
- カード・画像・ページ送り・ビューア、作者と似た作品への遷移、カードサイズ、タグと検索、選択と一括保存、更新、鮮度・取得失敗・キャッシュ保存先の表示を継承。サービスのキャッシュを単一の供給元とする。DL 状態の反映には既存のスナップショット・世代・再投影を使い、作品閲覧中は表示中のカードを動かさない。
- 見出しの直下に、ライブラリは「このPCに保存した作品」、マイブックマークは「Pixivでブックマークした作品」。カードには「保存済み／未保存」を出す。空状態は現行の文言を使う。「pixiv本体も含む」は DL済み側の検索範囲で、「一覧を絞り込む」と通信を伴う「pixiv本体を検索」を別の操作にする。借用の準備中、許可後・解除後の再検索、失敗からの再検索、遅延結果の破棄を維持する。借用状態の変更は既存認可経路から通知する。
- 既存キャッシュを採用し、有効かつキャッシュなし／120 秒以上で自動更新する条件を初回と再活性化で評価。別アカウント・取得停止中は既存の許可範囲で直前のキャッシュを残し、注意書きで理由を知らせる。別アカウントの新しいデータを混ぜない。作品キー・選択・スクロール・フォーカス、ライブラリの作者詳細をタブ往復で復帰し、検索語はタブごとに独立させる。非アクティブ化で遅延ビューア・似た作品・画像セッションを失効。複数メディア、イラストのみ、サンプル、読み取り専用、イラストのない構成を検証する。
- 検索結果の更新・並べ替え、マイブックマーク⇄ライブラリの往復では、タブごとに選択とフォーカスを安定した作品 ID で照合する。同じ作品が別の位置に移動しても、選択とフォーカスはその作品に復帰する。選択した作品の同一性を確認できなければ、選択を解除し、フォーカスを一覧の見出しへ戻す。同じ位置の別作品を自動選択しない。作者一覧から作品一覧へ入るときも見出しにフォーカスし、作品は明示操作で選ぶ。

### 自動処理ダイアログ

上限付きの幅と高さで、ヘッダーと切替を固定し、本文だけスクロールする。ダイアログの上部と設定の「自動処理」節は、同じ要約を処理ごとに各 1 行表示する。内容は状態・最終実行・次回予定・失敗の有無。詳細は「定期チェック」「メタデータ補完」に切り替え、初回だけ既存ビューを生成する。再表示時も未保存値と処理結果を保持し、所有者・版が変われば既存の検証に従う。設定には各詳細への入口を置き、自動補完の設定スイッチは既存の「作品メタデータ」に置く。「起動時にもチェック」、間隔、停止と再試行、保存、履歴、台帳は各詳細で扱う。

共有ログはダイアログの共通の折りたたみ領域へ移す。既存の開閉・順序・所有者検証を引き継ぎ、切替で複製しない。定期チェックの詳細更新には照合と画面内通知の副作用がある。既存ランナーの照合・デスクトップ通知を維持し、画面内通知の配信をダイアログの可視性から切り離す。共有の原子的な claim、送達直前の所有者検証、既存の通知条件を守る。

| 状態 | 観測する事実 | 右上の表示 |
| --- | --- | --- |
| 待機中・実行中 | 予定待ち・一時保留、または現所有者の受理済み実行。詳細に状態と理由を出す | 無印 |
| 失敗・未確認／確認済み | 現所有者の未解消エラー・中断／結果未確定や補完の要確認。確認済みは「見た」という意味 | 感嘆符と常設の未解消総数。「未確認 a／確認済み b」を補助表示 |
| 停止要求中 → 停止成立 | 通信中の停止要求と、停止が成立した時点を別々に表示 | 手動の停止要求・停止成立は無印 |
| 停止（設定で OFF） | 利用者が自動処理を無効にした。詳細・ツールチップ・読み上げ名に理由を出す | 無印 |
| 意図に反する停止 | 取得停止ゲート等で有効な自動処理が止まった。理由と回復の導線を表示 | 停止マーク |

失敗と意図に反する停止が重なれば失敗のバッジを優先し、理由は処理ごとに読めるようにする。未提供は「利用不可」、読取り不能は「状態を確認できません」。ダイアログを閉じていてもヘッダーに「自動処理：未解消 N」を主表示し、「未確認 a／確認済み b」を添える。読み上げ名でも未解消の総数と内訳を区別する。発生・解消はヘッダー直下の細い `role=status` 行で通知し、フォーカスは移さない。640 CSS px 以下では件数と内訳を表示し、個別の発生・解消は同じ `role=status` で読み上げ、処理名と理由はダイアログで確認できる。確認済みにしても総数に含める。次の成功、または設定変更で原因が解消したときだけ該当処理を件数から外し、全件解消したら常設表示を消す。複数の失敗は状態行と要約に並べる。状態遷移、バッジ、共有ログ、読み上げ名、両方の要約を同じ更新から反映し、時系列の一貫性を実装の受入試験に含める。

定期チェックとメタデータ補完は、停止要求中・手動停止成立・設定 OFF・取得停止による保留を同じ作法で区別する。取得停止による保留には「取得停止の確認・回復」への入口を出す。取得停止を解除すると予定待ちに戻り、未解消の失敗は次の成功または原因を解消した設定変更まで残す。

再編後の最初の起動だけ、自動処理アイコンに「定期チェックとメタデータ補完は『自動処理』に移りました」と案内する。表示済みの採番は既存設定と分離し、再起動やパネルの開閉で繰り返さない。案内を閉じた場合はアイコンへフォーカスを戻す。

**監視。** 現行の詳細 UI は両方 5 秒。シェルの 1 秒タイマーは借用同期と視覚学習の状態表示に使う。推奨案はサービスの既存遷移から所有者検証済みの要約 2 件を保持し、UI は更新差分だけを描く。既存イベントを優先し、必要な場合はクライアントに最大 1 つの 1 秒タイマーでメモリの要約だけを比較する。閉鎖中は詳細 UI のタイマー、台帳集計・履歴取得、通信を行わない。開いた時と表示中だけ、選択中の詳細を即時および現行の 5 秒間隔で更新する。再入防止、閉鎖・切替後に反映しない世代確認、切断時のタイマー／購読解除を行い、所有者変更で古い状態を落とす。バックグラウンドの既定・間隔・開始条件は現行契約を維持する。

**操作。** 入口に `aria-haspopup=dialog`、ダイアログに可視見出しとモーダルの意味を付ける。利用できるパネルから失敗中 → 実行中 → 定期チェック → メタデータ補完の順で最初の選択を決める。設定と起動からの明示パネルを優先する。開いたら選択中の内側タブにフォーカスを置く。左右矢印／Home／End で移動し、Tab／Shift+Tab は本文と閉じる操作をモーダル内で巡回する。Esc は上に開いた確認・ポップオーバーを先に閉じ、IME 変換を尊重する。閉じたら背景タブの入力・位置・選択を保ち、入口にフォーカスを戻す。設定入口は設定を閉じてから開き、閉じたらヘッダーの設定へ。起動指定時は自動処理ボタンへ戻す。切替・閉鎖中も処理は続き、明示の停止ボタンから停止要求する。

**代替案。** 縦積みは両方を同時に見られるが、台帳とログが縦に並び停止操作まで遠くなる。アコーディオンは両要約を見せやすいが、展開位置・フォーカス・監視の調停が増える。2 画面を常時 1 秒でポーリングする案は、クライアント数に比例して台帳アクセス・照合・通知の負荷が増える。ダイアログ内切替と小さい要約を採る。

| `history` | 既存のバックアップ画面。利用不可の構成は従来の既定へ |
| `personal`、`bookmarks` | カスタムランキング、マイブックマーク（公開する追加キー） |
| 明示した `--tab scheduler`、`--tab metadata` | 背景はダウンロード。シェル準備後に自動処理を一度だけ開き、該当パネルを選択する。利用者が明示した起動操作のため。処理は既存の既定・設定または明示操作に従う |

今後、起動先を保存する設定を設ける場合の優先順は「明示 CLI → 保存された通常タブ → ダウンロード」。自動処理ダイアログの起動時自動表示は明示 CLI 限定。旧値・内部引数の `scheduler`／`metadata` は通常起動でダウンロードへ読み替える。既存ファイルはキー欠落のまま読める。 `startup_tab.py` に表示順と別の定義を集約し、`bootstrap.py` から明示性を引き継ぐ。既定・明示優先・未知値・利用不可・履歴互換・両ダイアログ指定と復帰を試験する。

### よく効くタグ

- 共通の折りたたみツールバーの展開内に候補を 1 行。カスタムランキングで候補があれば初回展開済み。明示済みの `ranking_personal_candidates_open` を優先し、欠落時は開く。カスタムランキングの開閉操作は候補副行と共通ツールバーを一緒に開閉し、同キーを保存する。閉じている間も「よく効くタグ（N件）」の入口を出し、そこから展開できる。候補がなければ入口を省く。既存候補の順・選択処理・上限は FL-Y02 に従い、選択タグ・主操作・エラー・取得停止を固定領域から操作できるようにする。
- 見出しと `+N` の幅を確保し、入る先頭候補を並べる。全部入ればボタンを省き、極狭幅で候補が入らなければ全件を `+N` に畳む。フォント・倍率・文字幅を実寸で再計算する。長い候補はポップオーバー内で折り返す。開いていない候補はフォーカス経路から外す。
- `+N` に「ほか N 件」のツールチップ、「残り N 件のよく効くタグを表示」のアクセシブル名、`aria-expanded` と対象の関連を付ける。Enter／Space で開き、Tab で候補へ移動し、Esc・外側クリック・選択で閉じる。Esc と選択時は起点へ、幅変更で起点が消えたら同じ候補か親の開閉へ戻す。選択は既存のタグ追加・検索経路を再利用する。ポップオーバーの開閉は一時状態。横スクロールの代替は残り候補の存在と件数が分かりづらい。

## 画像の表示面積と共通ツールバー

全タブで手動折りたたみを共通部品にする。閉じた行は画面名、選択中の条件、主要操作、開閉ボタンを基本にし、件数・時刻は末尾または狭幅時の補助行へ置く。展開内に検索、カードサイズ、順序、対象範囲、候補やフィルターを集める。画面ごとに開閉状態を保存し、選択・入力・スクロール位置を維持する。停止・通信結果未確定・読み込み・エラーの表示と必要な操作は固定する。展開ボタンに `aria-expanded`／`aria-controls`、Esc の復帰、IME の変換優先を適用する。スクロール方向に連動する自動開閉は不採用。

| --- | --- |
| ランキング 2 画面 | 取得前後の主操作と結果状態を同じ位置に置く。検索・サイズ・絞り込みを展開内へ |
| ライブラリ／マイブックマーク | タブを分け、作者詳細の戻りを固定。検索・サイズ・範囲・並び順は展開内へ |
| 重複整理・おすすめ | スキャン・モード・隔離確認や取得状態を固定し、棚見出しとカードは一緒にスクロール |

先行設計の 1950×1030 実画面では、カスタムランキングの一覧 y=523.5、画像 y=560.2、一覧 47.7%。一方、一覧を y=196 から、左右計 20px と下 10px を除く領域に置く計算は、1280×800 で 73.1%、1920×1080 で 80.1%、1950×1030 で 79.2% の**試算**。折りたたみ、ヘッダー詰め、タブ行の削減の効果は重なり、単純加算しない。先行設計の比較表と基準資料を参照用に残す。[画像面積の先行設計](UI_IMAGE_AREA_20261122.md)

製品では A17 を画面ごとに判定する。1280×800 は 55%、1920×1080 は 60%、1024×768 は暫定 40%。1280×800 の 125%（実効 1024×640）は、通常と長文 DB 警告＋取得停止＋未解消の失敗 2 件が併発した状態の両方で、絞り込みを畳んだときの合格を必須とする。展開時は手動で畳めるため、実測を参考値として併記する。125% のしきい値は同倍率・同条件の改修前の現行 Flet 並置と現行 NiceGUI を製品で計測して決める。1024×768 の暫定値 40% はそのサイズに適用する。

固定 640×400 CSS px と 1280×800 相当のページズーム 200%（実効 640×400）は、両条件で A11 と完全表示枚数を確認する。長文 DB 警告・取得停止・未解消の失敗 2 件が併発し、絞り込みを畳んだ初画面では、先頭画像がキャプションを除いて全体表示され、完全表示画像が 1 枚以上あることを必須とする。展開中は一覧が一時的に狭くなる。画像 0 枚を許容し、「絞り込みを畳む」は絞り込みと一覧をスクロールしている間も常時見える位置に固定する。キャプションまで収まるカード数と面積割合は参考値。学習の画像下限と判定四択の操作可否は独立に確認し、200% の下限は製品比較で決める。四択は見送る・合わない・いいね・SuperLike。同じ 1200×900 素材の既定の下限は 1024×768 で 525.3×394.0、1280×800 で 618.6×464.0、1920×1080 で 1042.6×782.0、1950×1030 で 976.0×732.0 CSS px。

可視幅×可視高の割合、一覧／画像先頭の y、見える画像数、完全表示枚数、画像自体の可視寸法を記録する。既定の 112 条件を維持し、追加倍率・警告や停止・展開条件を別行で追う。

A1 は小さい太字も 4.5:1、大きい文字だけ 3:1（通常 24px 以上、太字 18.7px 以上）。状態は文言・記号で区別し、読み上げとフォーカス復帰を確認する（A12/A13）。動きを加える場合は `prefers-reduced-motion` を尊重し、重要な通知は明示操作まで残す（A14）。ライト・ダーク、空・長文・エラー・取得停止、125%・200% を計測し、Flet 並置・B9・Native の証拠を回収する。[監査仕様](../UIUX_AUDIT_SPEC_20261122.md)

ワイヤーフレームは起動時にダウンロードを表示する。カスタムランキングで初期の候補と `+N`、学習で画像と判定四択を操作できる。設定の「ワイヤーフレームの表示例」から本番 DB 警告（通常・長文・表示なし）と取得停止を切り替えられる。「閉じて失敗を再現」で未確認の通知、「確認済みにする」で未解消の小さな表示、「次の成功を再現」で解消まで試せる。停止要求と成立は個別の操作で確認する。 `?tab=scheduler`／`?tab=metadata`／`?tab=bookmarks` で起動先を試せる。警告・画像・結果は合成データ。
