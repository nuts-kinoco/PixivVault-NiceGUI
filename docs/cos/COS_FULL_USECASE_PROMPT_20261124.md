## 前提

- Windows の PixivVault NiceGUI を監督（Claude）が起動済み。実機の画面は `http://127.0.0.1:22386/`。借用プレミアム ON、ログイン有効、入力不要。候補・隔離または実プロファイルの区別・退避と照合の担当・撮影先を監督から受け取る。応答なし、起動保護の警告、認証要求があれば、その時点で中断して安全な証拠と理由を返す。
- 監督が D6 測定と競合通信が終わったこと、取得停止状態、保留ジョブ・自動処理、通信枠と安全な閲覧経路を事前確認する。カード表示・タブ活性化・下端付近へのスクロール・フォーカス確定でも通信し得る。副作用を事前に限定できない画面は、監督が用意した結果・隔離画面・証拠で見る。
- 証拠は監督指定の S: 上へ保存する。実アカウント・作品・作者の識別値、認証情報、実画像、個人パスを回答・画像・ログに残さない。伏字を保存前に適用できない場合は、観測した安全な要約を記録する。

## してはいけないこと

- CoS は画面の観察と表の「実機」列に指定したクリック・キー操作を行う。起動・終了・再起動、シェル・コード・テスト・API 直呼び、他の窓や OS の設定を操作しない。設定の保存、資格情報の閲覧・入力、外部リンク、登録・解除・同期、書き込み・削除・実ダウンロードは本人または割当済みの監督が扱う。
- 画面上にある確認や復帰の操作は入口まで見る。確認の確定、再確認の送信、回復、正式移行、通知の既読化、学習判定、☆、カードサイズ等の保存、借用スイッチ、タグ確定は押さない。テーマはこの候補のヘッダー内表示切替のみ、監督が一時切替と復元を確認できる場合に各方向 1 回。
- シナリオは各項目を実施する順序。通信枠を使った項目は再実施せず結果を参照する。連打・自動再試行の誘発を避け、処理中には次の通信操作に進まない。429・共有停止・不明な反応・予算超過の兆候が出たら以後の実通信を止める。保留枠の流用なし。
