## してはいけないこと
- 設定の保存・変更、借用プレミアムの ON/OFF、パスワード・Cookie・トークンの入力、ファイルの削除、「ごみ箱を空にする」「削除」「取得停止の回復」「正式移行を実行する」などの不可逆な操作。
- **ダウンロードの実行・定期チェックの今すぐ実行・☆の保存・フォロー同期は押しません**（実通信と保存が起きるため）。表示と、開閉・並び替え・切替のような表示だけの操作にとどめます。
- Cookie の値・アカウント ID・作品の画像が大きく写る画面のスクリーンショットは撮りません（撮る場合は、その部分を切り取ります）。
- 迷ったら押さずに、その状態を報告します。
- 例外: ヘッダーの「ライト/ダーク切替」は、テーマ確認のために押してかまいません。確認後は最初のテーマに戻します。

## 確認項目（各項目に PASS / FAIL / 判定不能 と、見たままの文言を記録）
**判定不能にするときは、「何が足りなかったか（証拠・発生条件・操作方法）」を 1 行で書きます。**

A. R3 の FAIL の再確認（修正済みのはず）
 A1（E1）. 「ランキング」→「自分のランキング」に切り替えても、共有ログ欄が表示されない（元と同じく、共有ログ欄は主要 9 タブでは出ない）。通常ランキング・他のタブでも出ないことを記録する。
 A2（C1）. 定期チェック画面に、**どのアカウントの定期チェックか**（「紐づけアカウント：確認済み」などの表示）が出る。アカウント ID は書かず、表示の有無と文言だけ記録する。別アカウントや確認できない場合は ID を出さない作りなので、出ていないときは文言を書く。
 A3（G1）. 学習画面で画像の読み込みに失敗した場合（HTTP 404 など）、その表示が**学習のカードの中だけ**にあり、他のタブ（ダウンロード・ライブラリ・ランキングなど）に残らない。自然に失敗が出なければ「判定不能（失敗が発生しない）」でよい（失敗を起こす操作はしない）。
 A4（F2）. 重複整理のごみ箱ダイアログ（開くだけ。実行しない）に、「旧ごみ箱を開く」の表示が**無いこと**は元の Flet 版と同じ（元に存在しない操作）。ダイアログ内の操作名を、見たまま全て記録する（「保存先を開く」などがあれば押してよい。エクスプローラーが開くだけ）。
 A5（ビューア中の画面切替）. ライブラリで作品を 1 つ開いて拡大し、**1 分間、操作せずに表示したまま**にして、意図しない画面切替・ビューアの閉じ・画像の消失が起きないことを確認する。続けて、拡大・縮小・ドラッグを行い、Esc で閉じたとき、元の作品カードに戻ること（フォーカスが元の位置に戻る）を記録する。
 A6（ローカルタグ補完の表示）. 設定ダイアログ（変更しない）の画像タグ補完（ローカルモデル）の欄が、「有効」と表示されるのは実際に使える場合だけで、使えない場合は理由付きの「無効」（例: 依存ライブラリ不足）と表示される。見たままの文言を記録する。
 A7（おすすめの未接続表示）. おすすめ画面で「未接続」と表示される取得元がある場合、その文言と、設定確認の案内の有無を記録する。保存結果が無いだけの節には「未接続」と出ない。

B. R3 の判定不能の再確認（前回は証拠不足）
 B1（B3）. ダウンロード画面の対象種別ボタンを押すと、イラスト・漫画 → 小説 → 両方 の順に循環する。**押した瞬間にボタンが一度沈んで戻る**ことを、押下中の画面（または動画・連続画面）で確認する。確認できる手段が無ければ「判定不能」と書き、できなかった理由を 1 行書く。
 B2（B6）. 作者の行の☆が、表示中のアカウントのものとして見える。**アカウントを切り替える操作はしない**（設定変更になるため）。☆の表示と、行の☆の状態（ON/OFF の数）だけ記録する。アカウント別の独立性は自動試験で確認済みなので、ここは見えたままでよい。
 B3（F1）. ライブラリの作品を拡大し、マウスで**連続して**ドラッグ（左→右→上→下と 5 回以上続けて）しても、画像が途中で止まらず追従する。止まる場合は、何回目で止まったか、止まった位置を書く。
 B4（H2）. 「ランキング」→「自分のランキング」で、AI／非AI の絞り込み（AI 除外のスイッチなど）を切り替えて、表示件数の増減を記録する。「もっと見る（続きを取得）」で 30 件 → 60 件になることも記録する。AI 作品と非 AI 作品の表示の違いが見える場合は書く。
 B5（H3）. タグ・期間・サーバー側条件を**続けて**変えたとき、最後の条件の結果になる（途中の条件の結果が最後に残らない）。タグは入力の途中の文字（1 文字ずつ）では検索されず、追加（Enter など）を確定したときに検索される。見たままを記録する。
 B6（H4）. 取得が失敗した・共有停止中のとき、原因が識別できる表示（準備中／共有停止／通信障害の別）が出て、直前の結果が残る。**失敗を起こす操作はしない。**たまたま出た場合だけ文言を記録する。出なければ「判定不能（失敗が発生しない）」でよい。

C. 画面デザイン（P5 の修正。元の参照画像と並べて見る）
 C1. マイブックマーク: カードがあるのに「取得に失敗しました」だけが出る状態になっていない。保存済みの表示と取得失敗の表示が矛盾していない（検索語を入れて 0 件にしたとき、「保存済みのブックマークを表示しています」と出ない）。1280×800 で、カードの選択チェックが見える。
 C2. ランキング（公式）: 期間（日間・週間・月間・新人）がピル型のチップ、R-18・AI 除外がスイッチ（元の見た目）。
 C3. 設定ダイアログ: 角丸があり、グループ分けのカードがあり、同期・キャッシュ削除・エクスポートなどの操作が淡いアイコン付きのボタンで表示される。上から下までスクロールして、はみ出し・重なり・文字切れがない。折りたたみ項目があれば開いて、同じく確認する（設定は変更しない・保存しない）。
 C4. キュー（空）: 「現在のジョブはありません」が表示される（iOS 連携の案内文は表示対象外）。
 C5. 重複整理: サイズ切替が小・中・大の順でアイコン付き。見出し「重複候補の確認」が明朝体。キューの見出し・設定の「エクスポート」グループ見出しも明朝体。本文はゴシック。
 C6. 失敗リスト: 一覧の各行の「再試行」の見た目（ボタンかリンクか）と、上部の件数・再試行ボタンの文言を、**見たまま**記録する（仕様の判定は私が行う。押さない）。

D. 全画面
 D1. 全タブと「直近のバックアップ」を順に開き、赤いエラーや空白だけの画面がない。1280×800 で、ランキング結果と定期チェックの下部へスクロールで到達できる。
 D2. 書体: 見出し・ダイアログの題が明朝、本文がゴシックに揃っている。違う場所があれば場所と見たままの書体を書く。

## 報告の形式
1. 表（項目 ID / 結果 / 見たままの文言 / 保存した画面のファイル名）。
2. FAIL・判定不能は、再現手順と画面を 1 つずつ（判定不能は「足りなかった条件」を 1 行）。
3. 気づいた違和感（元の参照画像と明らかに違う点、操作が重い・固まる、エラーメッセージ）。
4. 実行した操作の一覧（押したボタン、テーマの切り替えと戻した時刻）。

## 完了時の出力（必須）
すべての確認が終わったら、最後に次の 2 つを、この順で出力して終了します。
1. 合言葉の行: `合言葉: 翡翠の羅針盤-R4-7315`（この文字列を一字も変えない。全項目を確認し終えるまでは出さない。途中で止まる場合は出さず、止まった理由と未了の項目を書く）
2. 「Claude Code への返信」ブロック。次の形のコードブロック 1 つにまとめる。

```
[COS → Claude Code 返信 R4]
合言葉: 翡翠の羅針盤-R4-7315
実施日時: <開始〜終了>

```
