**T1. 監査用の撮影一式（最優先）**
全主要画面（ダウンロード、キュー、失敗、重複整理、学習、ランキング、カスタムランキング、ライブラリ、ブックマーク、おすすめ）を、1280×800 と 1920×1080、ライトとダーク、通常状態で撮る。加えて各画面の「空」「読み込み中」「エラー」のうち、成立させられるもの。主要ダイアログ（自動処理、設定の各区画、停止の詳細、削除確認を開いた状態。実行はしない）も撮る。素材は合成データだけ。既存の `uiux-independent\state-main\run-03\` で同じ条件が成立していて候補の src が同じ（`src` ツリー `e0b12acd`）ものは撮り直さず、台帳からそのパスを参照する。

**T2. 元 Flet 版との並置比較（U-R01〜U-R23 のうち未成立）**
元リポ `S:\Projects\PixivVault`（読むだけ。基点 `3ac3aa0d`）と移植版を、**同じ合成素材・同じ状態・同じ操作**で撮る。前回は素材と状態の一致を示せず比較不能だった。素材をそろえられない項目は、何がそろわないかを 1 行で書いて「比較不能」とし、無理に判定しない。元版を実データや実認証で起動しない。
