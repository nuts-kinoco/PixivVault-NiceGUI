## 前提
- アプリは Claude Code 側で起動済みで、借用プレミアムは ON です。**あなたは起動・再起動しません**。`http://127.0.0.1:22386/` が応答しない場合や、「PixivVault — 起動設定の確認」「STOP保護または設定の保存状態を確認できません」の画面が出る場合は、確認を始めず、その画面を保存して報告し、終了します（合言葉は出しません）。

## してはいけないこと

- ダウンロードの実行・定期チェックの今すぐ実行・☆の保存・フォロー同期・学習の判定（好き／スキップ／嫌い）・ブックマークや Like の送信は押しません。
- ランキングの「取得・更新」は、**項目 B で指定した回数だけ**押します（実通信が起きるため。連打しない。1 回押したら結果が出るまで次を押さない）。
- 迷ったら押さずに、その状態を報告します。ヘッダーの「ライト/ダーク切替」は押してかまいません（確認後は最初のテーマに戻す）。

## 確認項目（各項目に PASS / FAIL / 判定不能 と、見たままの文言・体感を記録。判定不能は「何が足りなかったか」を 1 行で）
A. 起動直後・ヘッダー（操作しない）
 A1. ヘッダーに、本番 DB の警告（1 行の要約。「詳細」で全文が開く）、ロゴ、ログイン状態、借用スイッチ（ON のまま・押さない）、「取得停止の確認・回復」の入口、右上のアイコン 7 個（バックアップ履歴・閲覧履歴・保存先・テーマ・Web・設定・自動処理）が、重ならず 1 画面に収まっている（1280×800 と 1920×1080）。
 A2. 約 1 分見ていて「[通信停止中]」「取得または待機を中止しました」が出ていない（出ていれば、いつ出て、いつ消えたか）。「自動処理：未解消 N」が出ていれば、N と内訳（未確認／確認済み）を記録。
B. 新しいナビ
 B1. タブが 10 個で、並びは設計どおり（ライブラリの隣に「マイブックマーク」が独立。「カスタムランキング」という名前がある［旧「自分のランキング」］。「定期チェック」「メタデータ補完」はタブに無い）。1280 幅で 1 行に収まる。
 B2. 右上「自動処理」アイコンでダイアログが開き、定期チェックとメタデータ補完の要約（最終実行・次回予定・失敗の有無）と詳細、状態バッジの意味が読める（設定で OFF のものは警告色にならない）。Esc で閉じ、閉じた後フォーカスがアイコンに戻る。**「今すぐ実行」は押さない。**
 B3. 設定の「自動処理」の節に、2 つの処理の要約が 2 行ある。
 B4. （初回だけの案内が出ていれば）「定期チェックとメタデータ補完は『自動処理』に移りました」の趣旨の案内が一度だけ出て、閉じられる。出なければ「表示なし」。
C. 画像の面積（本人の最重要要求）
 C1. ランキング・カスタムランキング・おすすめ・ライブラリ・マイブックマーク・学習の各タブで、画像・カードが表示されている範囲が「広くて見やすい」か。画面の上半分以上が操作部品で埋まっていないか。体感を記録（狭いと感じたタブは、画面名と理由を一言で）。1280×800 と 1920×1080 の両方。
 C2. 手動の「折りたたみ」（ツールバー）を開閉して、画像の領域が広がる／戻る。折りたたんでも、取得停止の入口と未解消件数は見えたまま。
 C3. ウィンドウの幅を狭める（約 1024 幅、さらに約 640 幅まで）と、タブが等幅 2 段、さらに開閉式のナビに変わり、画像が 1 枚以上見える。ナビを開いて Tab で外へ出ると、ナビが閉じてフォーカスが見える（取得・更新ボタンなどが覆われない）。Esc で閉じる。
D. よく効くタグ・往復
 D1. カスタムランキングの「よく効くタグ」が 1 行に収まり、あふれた分は「+N」（押すと一覧。「ほか N 件」の表示）。折りたたむと候補数の入口が残る。2 段に折り返していない。
 D2. ライブラリで作品を 1 つ選び、マイブックマークへ移動して戻る。選択・スクロール位置・フォーカスが保たれる（別の作品にすり替わらない）。検索語はタブごとに独立。見出しの下の説明と、カードの「保存済み／未保存」の表示がある。
E. キーボード・フォーカス
 E1. 設定ダイアログを開き、Tab・Shift+Tab を押し続けても、フォーカスがダイアログの外（背景）へ抜けない。Esc で閉じ、閉じた後フォーカスが設定ボタンに戻る。
 E2. 通知（トースト）が出ていれば、「閉じる」で閉じた後、フォーカスが失われない（画面のどこかに有効なフォーカスが残る）。
F. 借用（実通信あり）: **R7 の B〜D（ランキングの期間切替 4 回の「取得・更新」、カスタムランキングのタグ編集［検索は実行しない］、借用による個人検索 1 回）と同じ手順・同じ回数制限**で行う。ランキングの「取得・更新」は、期間ごとに 1 回ずつ（合計 4 回）、個人検索は 1 回だけ。連打しない。エラーが出たら文言をそのまま記録し、1 分待って 1 回だけ再試行。
G. 全体
 G1. 全タブと「直近のバックアップ」を順に開き、赤いエラーや空白だけの画面がない。
 G2. 最後に、借用スイッチが ON のまま、「[通信停止中]」が出ていない。

## 報告の形式
1. 表（項目 ID / 結果 / 見たままの文言・体感 / 保存した画面のファイル名）。
2. FAIL・判定不能は、再現手順と画面を 1 つずつ。
3. 気づいた違和感（元のアプリの使い心地と違う点、重い・固まる、画像が狭い、エラーメッセージの分かりにくさ）。
4. 実行した操作の一覧（押したボタンと回数、テーマの切り替えと戻した時刻、取得・更新を押した回数）。
