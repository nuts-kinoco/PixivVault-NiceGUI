# COS R3 追補（公式45残件・P4）

既存の [R3](COS_REALAPP_PROMPT_R3.md) の前提、禁止操作、報告形式を適用する。開始前に監督から対象候補のコミットと画面の起動状態を受け取る。記録は R3 の S: の証拠フォルダーに置き、作品・作者・アカウントの識別子や Cookie・トークンを伏せる。下表の各項目を PASS / FAIL / 判定不能 で報告し、見た文言、手順、画面ファイル名を添える。

## 操作が承認された隔離試験で追記する項目

監督が承認済みの隔離構成を用意し、R3 本文が禁止している操作は担当者が行う。COS は結果画面と操作を照合する。対象データ、実施者、許可のいずれかが揃わなければ判定不能とする。

| 原ID | 用意する条件と記録する結果 |
|---|---|
| U16 | 保存先を使える構成と使えない構成で、カードの右クリック項目と案内を確認する。使える構成では右クリックと詳細の単一ID入力を別々に試し、同一作品が受付に出ることを確認する。確認だけでは増えず、明示操作で受付が増え、再度の同一作品保存で保存物が重複しないことを照合する。 |
