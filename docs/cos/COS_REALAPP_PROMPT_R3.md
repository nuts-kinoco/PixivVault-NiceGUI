## してはいけないこと
- 設定の保存・変更、借用プレミアムの ON/OFF、パスワード・Cookie・トークンの入力、ファイルの削除、「ごみ箱を空にする」「削除」「取得停止の回復」「正式移行を実行する」などの不可逆な操作は押しません（ダイアログを開くのは可、実行は不可）。
- **ダウンロードの実行・定期チェックの今すぐ実行・☆の保存・フォロー同期は押しません**（実通信と保存が起きるため）。表示と、開閉・並び替え・切替のような表示だけの操作にとどめます。
- Cookie の値・アカウント ID・作品の画像が大きく写る画面のスクリーンショットは撮りません（撮る場合は、その部分を切り取ります）。
- 迷ったら押さずに、その状態を報告します。
- 例外: ヘッダーの「ライト/ダーク切替」は、テーマ確認のために押してかまいません。確認後は最初のテーマに戻します。

B. ダウンロード画面（元の参照画像と並べて見る）

C. 定期チェック

G. 全画面

## 報告の形式
1. 表（項目 ID / 結果 / 見たままの文言 / 保存した画面のファイル名）。
2. FAIL・判定不能は、再現手順と画面を 1 つずつ。
3. 気づいた違和感（元の参照画像と明らかに違う点、操作が重い・固まる、エラーメッセージ）。
4. 実行した操作の一覧（押したボタン、テーマの切り替えと戻した時刻）。
