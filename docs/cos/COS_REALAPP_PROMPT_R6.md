## 前提
- アプリは Claude Code 側で起動済みです。**あなたは起動・再起動しません**。`http://127.0.0.1:22386/` が応答しない場合や、「PixivVault — 起動設定の確認」「STOP保護または設定の保存状態を確認できません」の画面が出る場合は、確認を始めず、その画面の文言を報告して終了します。
- ウィンドウ幅は 1280×800 と 1920×1080 の 2 通りで見ます（特記以外は両方）。
- スクリーンショットは `S:\Projects\PV-DEV-20261117\verify\cos_<日付>_R6\` に保存します（C ドライブには保存しません）。認証 ID・アカウント ID・Cookie の値・作品の画像が写らないように加工してから保存します。既存の R4・R5 の証拠は削除・上書きしません。
- 借用プレミアムは ON のままです（OFF にしない）。

## してはいけないこと
- 設定の保存・変更、借用プレミアムの ON/OFF、パスワード・Cookie・トークンの入力、ファイルの削除、「ごみ箱を空にする」「削除」「取得停止の回復」「正式移行を実行する」などの不可逆な操作。
- **ダウンロードの実行・定期チェックの今すぐ実行・☆の保存・フォロー同期・ランキングの取得（「取得・更新」）・学習の判定（好き／スキップ／嫌いなどの学習ボタン）は押しません**（実通信と保存が起きるため）。ビューアの「原寸」「個別 DL」「保存先を開く」も押しません。表示と、開閉・並び替え・切替・拡大のような表示だけの操作にとどめます。
- 迷ったら押さずに、その状態を報告します。
- 例外: ヘッダーの「ライト/ダーク切替」は押してかまいません。確認後は最初のテーマに戻します。

## 確認項目（各項目に PASS / FAIL / 判定不能 と、見たままの文言・体感を記録）
**判定不能にするときは、「何が足りなかったか」を 1 行で書きます。** 体感の項目は「遅い・引っかかる」と感じたら、どの操作か・何秒くらいかを書きます（ストップウォッチは不要。目安でよい）。

A. ビューア（ライブラリ）
 A1. ライブラリで複数ページの作品を開き、**矢印キー（← →）とページ送りのボタン**でページを送る。押した直後に次のページへ切り替わり、ページ番号の表示（例: 2 / 5）と画像が食い違わない。体感の速さ（サクサクか、引っかかるか）を記録する。
 A2. 矢印キーを**連打**（10 回ほど素早く）しても、最後に止まったページの画像とページ番号が一致し、画面が固まらない・画像が前のページのまま残らない。
 A3. 拡大・縮小・ドラッグをしたあとにページを送ると、拡大が元に戻る（元の挙動）。Esc（または閉じるボタン）で閉じると、元の作品カードにフォーカスが戻る。
 A4. 作品を切り替える（別の作品を開く）ときに、タイトル・作者・タグ・ページ番号・画像が、**一瞬でも別の作品のものと混ざって見えない**。見えたら、どの組み合わせかを書く。
 A5. 作品を開いたまま **1 分間**放置しても、意図しない切替・閉じ・画像の消失が起きない。
 A6. うごイラ（動くイラスト）の作品がライブラリにあれば、開いて動いて表示される。無ければ「判定不能（該当作品なし）」。
 A7. 1280×800 と 1920×1080 で、ビューアの表示（画像の大きさ・ボタンの位置・文字の切れ）が崩れていない。

B. 作者検索（ライブラリ）
 B1. ライブラリの作者一覧で、検索欄に作者名を 1 文字ずつ入れて絞り込む。入力が引っかからず、結果が一定の間隔で更新される。体感を記録する。
 B2. 検索欄の文字を**素早く入れ替えて**（別の語を連続して入れる）も、最後の語の結果になる（途中の語の結果が残らない）。
 B3. 検索中・検索直後に、作者の並び順・容量の表示（「容量」「未計測」など）・「容量を測る」系のボタンが、おかしな状態（押せるように見えるのに無反応、更新されない）になっていない。ボタンは**押さない**（状態の見たままを記録）。
 B4. 検索欄を空に戻すと、全作者の一覧に戻る。

C. 学習・その他の表示
 C1. 学習タブを開く（判定ボタンは押さない）。カードの画像・タイトルが表示され、画像の読み込み失敗の表示が他のタブに残らない。
 C2. ライブラリ・ランキング・学習・おすすめ・定期チェックのタブを順に**素早く**切り替えて、画面が固まる・赤いエラーが出る・空白のままになることがない。体感の速さを記録する。
 C3. （借用が関わる表示のみ。操作はしない）ランキングの期間切替（日間・週間・月間・新人）の表示、ライブラリの検索スコープ切替の表示、「自分のランキング」のタグ入力欄の表示が、エラーなく出る。取得はしない。

D. 前回までの確認の続き（短く）
 D1. 全タブと「直近のバックアップ」を順に開き、赤いエラーや空白だけの画面がない。
 D2. 起動直後のヘッダーの下に、「取得または待機を中止しました…」「[通信停止中] …」が出ていない（出ていれば、いつ消えたかを書く）。

## 報告の形式
1. 表（項目 ID / 結果 / 見たままの文言・体感 / 保存した画面のファイル名）。
2. FAIL・判定不能は、再現手順と画面を 1 つずつ。
3. 気づいた違和感（元のアプリの使い心地と違う点、重い・固まる、エラーメッセージ）。
4. 実行した操作の一覧（押したボタン、テーマの切り替えと戻した時刻）。

## 完了時の出力（必須）
すべての確認が終わったら、最後に次の 2 つを、この順で出力して終了します。
1. 合言葉の行: `合言葉: 琥珀の灯台守-R6-4718`（この文字列を一字も変えない。全項目を確認し終えるまでは出さない。途中で止まる場合は出さず、止まった理由と未了の項目を書く）
2. 「Claude Code への返信」ブロック。次の形のコードブロック 1 つにまとめる。

```
[COS → Claude Code 返信 R6]
合言葉: 琥珀の灯台守-R6-4718
実施日時: <開始〜終了>

未了の項目: <無ければ「なし」>

```
