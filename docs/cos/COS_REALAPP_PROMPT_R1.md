使い方: 下の「--- ここから ---」から「--- ここまで ---」までを COS のチャットに貼る。結果（表と画面の保存先）を私に持ち帰る。
切り分けの基準: Claude 側は「コード修正・テスト実行・checker」を行い、COS は「実機の画面確認」だけを行う。1 回の貼り付けは 20 画面以内にする。

あなたは、Windows 上の PixivVault（NiceGUI 版・開発中）の「実機の画面確認」だけを担当します。コードの修正・テストの実行・設定の変更はしません。結果は表で返します。

## 前提
- アプリは `S:\Projects\PV-DEV-20261117\launch_work.ps1` で起動します（PowerShell、Windows）。すでに起動している場合は、そのまま使います（ポート 22386、`http://127.0.0.1:22386/`）。再起動が必要なときは、起動中の PixivVault の Python プロセス（ポート 22386 のもの）だけを `taskkill /PID <PID> /T /F` で止め、`launch_work.ps1 -Tag r_cos_<時刻>` で再起動します。ほかの python.exe は止めません。
- 画面は、アプリ内ブラウザ（またはお使いのブラウザ）で `http://127.0.0.1:22386/` を開いて確認します。
- 新しいファイル・スクリーンショットは、`S:\Projects\PV-DEV-20261117\verify\cos_<日付>_R1\` に保存します（C ドライブには保存しません）。
- 参照画像（元アプリの画面）は `S:\Projects\PV-DEV-20261117\verify\original_20261117_225445\` にあります（ファイル名は `<幅>x<高さ>_<dark|light>_<画面>.png`）。

## してはいけないこと
- 設定の保存・変更、借用プレミアムの ON/OFF の切り替え、パスワードや Cookie・トークンの入力、ファイルの削除、「ごみ箱を空にする」「削除」「取得停止の回復」「正式移行を実行する」などの不可逆な操作は押しません（ダイアログを開くのは可、実行は不可）。
- Cookie の値・アカウント ID・作品の画像が大きく写る画面のスクリーンショットは撮りません（撮る場合は、その部分を切り取ってから保存）。
- 迷ったら押さずに、その状態を報告します。

## 確認項目（各項目に PASS / FAIL / 判定不能 と、見たままの文言を記録）
A. 起動直後
 A1. 最上段に赤字で「⚠️⚠️ 本番DBを使用中: <パス>」が出ている。
 A2. ヘッダーに認証ラベルがある。起動から 30 秒以内に「● [有効] ログイン中 (有効期限 残り約N日) - ユーザーID: …」になる（「通信停止中」のまま変わらない場合は FAIL。何秒で変わったかを書く）。
 A3. 起動直後のタブが「ダウンロード」である。
 A4. ヘッダーに「借用プレミアム」のスイッチがある（現在の状態を記録。切り替えない）。
B. ナビ（タブ）
 B1. タブの並び（左から）を書き出す。
 B2. 各タブをクリックして、画面が開き、赤いエラーや空白だけの画面にならない（全タブ: ダウンロード、キュー、失敗リスト、直近のバックアップ、重複整理、学習、ランキング、ライブラリ、おすすめ、自分のランキング、定期チェック、メタデータ補完）。
C. 設定ダイアログ（開くだけ）
 C1. 次の項目が見える: 「作品メタデータ」（説明に「既定はON」）、「絵柄・構図の推論」（ON）、「借用アカウント自動更新間隔」（24時間ごと）、「ブラウザ拡張機能の受信」（ON）、画面下部の「ver 0.1.0a0」。値は変更しない。
D. ライブラリ
 D1. 作者カード「torino」（1点）が出て、サムネイルが表示される（空白・壊れた画像は FAIL）。
 D2. カードを開くと「我が麗しきスネージナヤ」が出る。
 D3. 「絞り込み」を開き、ブクマ数の下限を 1,000 にすると 1 作者のまま、8000 にすると 0 作者になる（確認後に「条件をクリア」で戻す）。
E. 重複整理
 E1. 入口に「ごみ箱 N件・容量」の形の表示がある（N が読めない間は「ごみ箱」のみ）。
 E2. ごみ箱ダイアログを開く（実行しない）。上から、タイトル、警告 1 行、件数入力欄、「閉じる」「空にする」の順に並ぶ。件数入力が空のとき「空にする」は押せない。
F. メタデータ補完
 F1. 「メタデータ: N / M 件（残り…）」「いま埋める」「取得処理: …」が出る。「いま埋める」は押さない。
G. 借用プレミアム
 G1. スイッチをクリックするとポップアップが出る場合は、項目（パスワード、Shaft 署名キー（任意）、UID 一覧 txt を選択）を記録し、「キャンセル」で閉じる。OFF のスイッチを ON にしようとする操作はここまで。ON の場合は、スイッチを触らない。
H. 全体の見た目
 H1. 1280x800 と 1920x1080 で、各タブに横スクロールバー・文字の見切れ・重なりがない（あれば画面名とサイズを書く）。

## 報告の形式
1. 表（項目 ID / 結果 / 見たままの文言 / 保存した画面のファイル名）。
2. FAIL・判定不能は、再現手順と画面を 1 つずつ。
3. 気づいた違和感（元アプリの参照画像と明らかに違う点、操作が重い・固まる、エラーメッセージ）。
4. 実行した操作の一覧（押したボタン、再起動の有無と時刻）。
