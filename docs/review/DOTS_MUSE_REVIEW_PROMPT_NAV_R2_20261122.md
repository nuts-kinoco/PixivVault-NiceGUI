## 見てほしい観点
1. **前回の High の解消**: (a) 新 10 タブ・本番 DB 警告・取得停止の入口・右上アイコン 7 個が、1 つの画面で同時に収まっているか（長文の DB 警告・失敗の表示中も）。(b) 閉じた自動処理の失敗が、見逃されない形で残るか（「自動処理：要確認 N」、ヘッダー直下の role=status の状態行、確認済み＝小さな表示で残る、意図した OFF は警告にしない）。(c) 画像・カード領域の割合の実測（1280×800、1920×1080、1024×768、1280×800 の 125%）と、学習タブの下限（画像の可視寸法、判定の四択の到達性）の扱いが妥当か。実測表の読み方（ワイヤーフレーム上の値であり、製品の A17 合格ではない）が正直に書かれているか。
2. **前回の Medium の解消**: 標準倍率の定義と 125% の 2 段、よく効くタグの初期状態と「ほか N 件」、設定側の要約、マイブックマークの説明・保存済み表示・往復の状態保持、再編直後のヒント、タブ名のツールチップ。
3. **新しい欠陥**: 統合の過程で入った矛盾、見た目や操作の破綻、200% 拡大時の扱い（実測では一覧の割合が 14.6%／11.6% まで下がる。ズーム 200% での扱いの設計は妥当か）、キーボード・フォーカス・読み上げ。
4. **残る判断**: まだ決まっていない点や、設計書に書かれていない前提。
5. **進めてよいか**: 製品への実装に進んでよいか、まだ直すか。

## してはいけないこと
コード・ファイルの変更、アプリの起動や実データの操作、実際の Pixiv や外部サービスへのアクセス、Cookie・パスワード・アカウント ID の入力や記載。「良いと思います」だけの返答。
