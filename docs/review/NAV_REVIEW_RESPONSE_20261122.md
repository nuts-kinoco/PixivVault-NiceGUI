## 質問への回答
- **標準倍率**: OS 100% 相当（1280 CSS px 以上でタブ 1 行）。125% は 2 段で、その A17 も合格条件。
- **1024×768 の A17**: 暫定しきい値 40% 以上（監査仕様に追記）。
- **本番 DB 警告の面積予算**: 警告帯は 28px 前提（現行）で、薄くしても消さない。ヘッダーの行数は、警告が出ているときも 1 行ずつ数えて予算に含める。
- **「API 切り替え」「取得停止の確認」**: 製品では常時操作できるスイッチとボタン。モックの状態テキストは簡略化で、作り直す。
- **ブックマークと保存済みの往復**: 検索語は独立。別アカウントや取得停止中は、直前の一覧（キャッシュ）を残し、状態の注意書きを出す（既存の挙動を維持）。
- **自動処理の「確認済み」**: 「見た」だけを指す。確認済みにしても、原因が解消するまで（次の成功、または設定の変更）は、小さな表示で残す。消えるのは解消のときだけ。複数の失敗が重なったときは、それぞれの状態を並べ、全てが解消して初めて「要確認」が消える。
- **内部キー**: `personal` など内部キー・設定キーは変えない（表示名だけ）。
- **OUTCOME.md（verify/ui-nav-20261122/r1）**: 設計の補足の検証記録。判定には使わない。必要なら中身を貼る。
