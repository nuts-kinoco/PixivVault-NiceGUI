## 修正後の入口と検証

`src` の QDialog 生成27箇所を `managed_dialog` → `bind_dialog_keys` に集約した。ダイアログ内の通常の移動は Chromium に委ね、先頭・末尾・Tab 順外からの移動は共通処理が端点へ戻す。Quasar の初期フォーカス指定と Escape の挙動、および既存の再描画後の復帰先を保持した。QMenu と QSelect は Quasar の処理を使用し、画集ビューアの元 Flet キー操作も保持した。

| 対象 | 実ブラウザーの証拠 |
| --- | --- |
| 設定、URI、視覚学習データ削除、借用・通信結果、保存先（単独・設定内）、停止移行／回復、共有取得回復 | `test_ui_fix2_dialogs_browser.py`、`test_visual_preference_browser.py`。見出しから逆方向、通常順と逆順、ネストした選択肢の Escape、開いたボタンへの復帰 |
| ランキング日付・非表示管理、閲覧履歴、開始日／終了日、ダウンロード詳細・キュー・失敗記録・ごみ箱 | `test_ui_common_browser.py` と `test_ui_fix3_browser.py`、`test_ui_fix4_20261122.py`。実画面の順送り・逆送りと閉鎖、削除で元要素が無くなったときの復帰 |
| 学習リセット、類似、小説、うごイラ、未フォロー作者、アカウント切替 | `test_ui_common_browser.py` の実コンポーネントを隔離ページに置いた試験。学習リセットは合成件数で通常入口を通し、類似・小説・うごイラのデータ取得は試験の対象外 |
| おすすめ非表示理由、メニュー・画集ポップアップ、QSelect | `test_recommendation_visual_browser.py` と `test_ui_common_browser.py`、`test_ui_fix2_dialogs_browser.py`。メニューの Tab／Shift+Tab と Escape、起点復帰、外部リンクを開かずに閉鎖 |
| 通知とその自己閉鎖 | 共通トースト4種×2配色。起点が無効・非表示・接続前の3条件。実 LearningView の接続前通知×2配色。取得停止通知はヘッダー・単独設定・埋込み設定それぞれで短期通知と固定通知を検証。4件の連続閉鎖では中間の閉じるにフォーカスを保持し、最後だけ退避 |

生の `ui.notify` / `ui.notification` は共通 `notify_action` 内のみ。短い操作結果は通常のタイムアウト、重要通知は明示的な閉鎖、保存完了のバーストは共有の更新可能な通知とした。固定通知は同じ描画世代の見えている項目にだけ確認を適用する。
