# r4 フォーカス復帰条件の棚卸し

対象は ui-integ の 8f1bdae。UI の復帰処理とその呼び出し、フォーカスを新規に置く処理、試験を照合した。

| 復帰を起動する経路 | 8f1bdae の判定 | r4 の判定と試験 |
| --- | --- | --- |
| 操作中の要素・親が削除、非表示、無効化、inert または aria-hidden。DOM 置換・表示領域のリサイズ | MutationObserver と resize。追跡済みの操作が消失し、現在のフォーカスが body または同じ要素 | 観測条件を保持。実行時にも body／復帰対象から離れていないことを共通関数で判定。削除・非表示・無効化・再描画・見出し・移動済みを Chromium で確認 |
| バックグラウンド中の DOM 変化・自動で消える通知 | DOM 通知は受けるが、非アクティブ中は復帰処理を中断し再判定の入口がない | window のフォーカス獲得時に同じ追跡状態を再評価。別タブへ切り替える間に操作を削除し、再アクティブ化して確認 |
| 明示的に消える Cookie 帯、作者・作品概要・ビューア、インライン通知とトーストの閉じる操作 | 呼び出し側ごとに body／領域内を判定。自動期限切れは DOM 観測 | 呼び出し側は閉じる領域を伝え、共通関数で実行時に判定。既存のクリック・キーボード・自動期限切れで確認 |
| QDialog の hide、Escape、元の操作の消失、入れ子 | Quasar 既定の復帰と hide 後の補助。明示起点があれば RAF で無条件に上書き | 明示起点を追跡。現在位置を実行直前に共通関数で再評価し、他の有効なフォーカスを保持。hide 後の RAF を遅らせ、キー操作で移動して確認 |
| キュー、重複、ごみ箱、失敗記録、ランキングとライブラリのカレンダー、保存先詳細の遅延復帰 | focus_after_dialog が再描画後に候補を解決し無条件で復帰 | 同じ実行時判定を通す。実際の focus_after_dialog の RAF 中に別のボタンへ移動して確認。各既存画面で起点復帰も照合 |
| 保存済み小説・うごイラのダイアログを閉じる | 非同期読込前の起点へ戻す。Quasar の既定復帰が非同期中の別の要素に向く場合あり | 読込前の起点と本体のアクティブ・世代条件を保持し、共通判定を使う。実行ボタン→非同期読込→閉鎖を確認 |
| インラインビューア、ライブラリ作家画面、学習概要、ブックマーク等の画面更新 | 復帰と、ユーザーが要求した新しい表示への初期フォーカス指定が混在。画面／世代の検証を個別に保持 | 閉鎖に伴う明示復帰経路を調べ、共通の実行時判定へ接続する。初期フォーカスと Tab 循環の制御は意図的なフォーカス移動 |
| ダイアログ内の Tab／Shift+Tab | 旧試験は期待値を実 DOM の tabIndex で計算するため誤った順でも通る | フォーカスの期待順をテスト側で固定。順序故障の注入で旧期待値の見逃しを再現し、新期待値で検出 |

取得通知の待機混在（M03）と閉じた設定の監視継続（M04）は fix-notice 第8回の取り込み後の対象。

## 実装と実測

実行時判定は focus_recovery.js に置いた。非アクティブ中に失った操作を保持し、前景復帰で同じ条件を評価する。明示的な復帰も現在の対象が失われた場合に限って実行する。再描画で起点が置換される確認やカレンダーは、閉鎖前に画面側が復帰を担当することを宣言する。実行に先行する別のフォーカス移動は保持する。初期フォーカスの配置や、ユーザーが要求したタブ切替・ビューア表示は復帰とは別の操作として扱う。

| 経路 | 原証拠 |
| --- | --- |
| 非アクティブ中の削除と前景復帰 | RED_M01／FOCUS_FINAL。Chromium で別タブが前面であることとバックグラウンド側の body を確認 |
| QDialog hide 後・再描画後の待機中にキーボードで移動 | RED／FOCUS_FINAL。RAF を保留して Tab を押し、新たなフォーカスが再開後に残ることを確認 |
| 要素無効化、期限切れ、明示的な閉じる、DOM 置換、見出しへのフォールバック | FOCUS_FINAL、RELATED の既存試験 |
| 固定の Tab 順、順序の故障、停滞 | RED_FIXTURE／FOCUS_FINAL。試験側の固定順を使い、3操作の順序の入れ替えを検出 |

初回の実行では隔離 Chromium のフォーカスエミュレーションが有効で、別タブが前面でも元のタブがアクティブと報告した。エミュレーションを対象ページだけ無効化し、背景側の DOM 変化の完了後に再アクティブ化することで M01 の既存不具合を再現した。途中の FOCUS_FIRST／DIALOG_DIAG は、試験のセレクター設定と、見出しへのフォールバックが再描画後の起点より先に走る回帰を検出した記録。両方を修正し FOCUS_FINAL で確認した。

### Quasar の外枠と中身が異なる時刻に消える経路

重複管理の隔離確認は、キャンセル後に外枠がまだ可視でも、中身のポータルが除かれた時点で閉鎖の復帰対象になる。観測では古い判定が画面見出しを先にフォーカスし、後続の復帰がその有効なフォーカスを保持していた。再描画後の起点を持つダイアログは中身の消失を使って先行フォールバックを抑え、遅延時の現フォーカス判定を通して閉じた画面の起点に戻す。既存の4例（明暗、全選択とグループ、Enter と Escape）を、REPAIR の試験対象に含めた。
