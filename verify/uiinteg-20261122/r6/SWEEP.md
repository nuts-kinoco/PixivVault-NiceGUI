# r6 フォーカス移動と表示範囲の棚卸し

土台は dafa5001。対象は Dots R5-M01 と R5-L01。チェック対象はフォーカス移動、その場の維持、スクロールを伴う経路。

| 経路 | 旧動作と可視性の条件 | r6 で確かめる動作 |
| --- | --- | --- |
| ビューア閉鎖後の通常復帰、再生成カード、ライブラリ作者一覧への復帰 | preventScroll。再生・再描画で行位置が変わる。表示判定は DOM の可用性で、スクロール範囲・前面を見ない | 実ライブラリ・ブックマークで、既に見えている起点の位置を維持。再生成された画面外の起点の中心が前面・ビューポート内になる |
| ダイアログ復帰、再描画後の確認操作、通知・メッセージ閉鎖、遅い小説／うごイラ、推薦の再描画 | pvFocus.restore。画面変更により起点がスクロール外になる。表示されない起点は既存の近傍・見出しへ | 共通の可視化を通す。非表示・無効・別モーダル・別の有効なフォーカスの既存制約を確認 |
| DOM 観測による無効化・削除・非表示・ウィンドウ再活性化、画集ページ矢印 | pvFocus.restore。表示可能な代替候補が画面外にあり得る | 同じ可視化。ユーザーのフォーカス移動、復帰を待つ間のホイール操作を保持 |
| CardGrid のメニュー閉鎖・失効 | CardGrid が拾った元カードを preventScroll で再フォーカス。エポックと接続を確認 | 共有の可視化を利用。メニュー既定の起点、旧世代、フォーカス所有の検査を維持 |
| タブ・学習表示・ビューアの初期フォーカス | 明示的な表示操作。表示切替直後に意図した要素を preventScroll で選ぶ | 初期配置は復帰と独立。現在の見えるタブ／ビューア上部を使い、表示開始で一覧のスクロールを強制しない |
| ブラウザーの Tab と端の循環 | ブラウザーの既定スクロール。コードで循環する端では通常の focus | キー起点の移動で、現在のフォーカスと実順を保持。画面外は既定のスクロールで追従 |
| 確認開始時の識別と復帰先の記録 | before-show では現在のボタンを Quasar に渡し、remember_focus は起点だけを保存。スクロールの変更なし | 起点の記録は元どおり。実際に戻す処理を共通部品で扱う |
| タイトルプレビュー、一覧スクロール位置の保存・再表示、メニューの表示開始 | 表示・スクロール操作。フォーカスの復帰とは別 | 利用者が現在のスクロールを選んだ後の復帰との競合を隔離試験で確認 |

真正の非表示（display:none、閉じた領域、inert）では元の操作が使えない。開閉状態を維持し、共通の代替先を使う。画像一覧のスクロールクリップと固定ヘッダー・ツールバーによる前面の遮蔽は、座標と前面要素で判定する。

日付の試験はプロセス内の合成時刻を注入する。月初の選択可能日1日と月末の全日選択可能を対象にし、正常順と内部の順序を壊した場合を確認する。

M03・M04 は fix-notice の取り込み後。通信・取得停止ゲート・429 即停止には触れない。

## ブラウザーでの実測範囲

| 条件 | 旧候補 | 修正後 |
| --- | --- | --- |
| 再生成後に画面外（ライブラリ、ブックマーク） | 2/2 でフォーカスだけ戻り、中心は画面外 | 2/2 でフォーカスと前面中心を確認 |
| 画面内の中心を固定ツールバーが覆う（両一覧） | 2/2 で中心が覆われたまま | 2/2 で遮蔽物の外に移動 |
| 再生成後も見えている（両一覧） | 2/2 で現在位置を保持 | 2/2 で同じスクロール位置を保持 |
| 再生成後の復帰を保留中に実ホイール（両一覧） | 2/2 で元カードにフォーカスを戻してしまう | 2/2 で選択した位置とその時のフォーカスを保持 |
| 月初、月末の正常順・入れ替え | 月初の入れ替えだけ実行準備に失敗 | 正常順2/2、入れ替え検出2/2 |

CardGrid のメニュー閉鎖は既存の表示世代と接続条件を保ち、別の有効なフォーカスを上書きしない。Quasar の素の QDialog と QMenu の既定復帰はピン留め版ソースで引数なしの focus を確認した。アプリ側が明示的に行う復帰は共通部品の可視化を通す。復帰準備の RAF では利用者操作の時点を照合し、同じ位置を維持して次の操作を続けられるようにした。
