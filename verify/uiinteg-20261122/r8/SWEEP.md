# UI 統合 R8 の棚卸し

| 経路 | 元の条件 | 検証 |
| --- | --- | --- |
| 固定通知と待機 | 停止は alert。視覚の秒数は更新し、毎秒の読み上げは発行しない | 既存の mixed 実ブラウザー試験 |
| 待機と通常状態の混在 | 待機側の秒数を抑制したまま、再試行開始・中止の変更も status で配信する | ヘッダーの実ブラウザー試験。M03 |
| 設定の通知監視 | ダイアログが開いている間だけ設定内の表示更新と状態監視を行う | 設定内埋込・単独起動設定を開く、閉じる／取消、再度開く。M04 |
| ヘッダーの通知監視 | 設定の表示状態から独立し、ページ破棄まで更新を続ける | M04 の同一ページで表示更新回数を計測 |
| 取得停止解除 | 凍結版の明示再確認、表示のリビジョン照合、通知ごとの所有側照合 | 凍結版の通知試験 |
| 通知ボタンの消失 | 共通フォーカス復帰で起点、近傍、見出しの順を守る | 既存のフォーカス・Tab 試験 |
