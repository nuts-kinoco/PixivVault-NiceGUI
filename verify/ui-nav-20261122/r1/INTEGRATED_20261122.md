## 再実行

作業ツリー直下の PowerShell で実行する。D6 の静穏フラグが存在する場合、スクリプトは Chromium を起動する前に終了する。

~~~powershell
$env:TEMP = 'S:\Work\_tmp\PV'
$env:TMP = $env:TEMP
$env:PYTHONUTF8 = '1'
& 'S:\Projects\PixivVault-NiceGUI\.venv\Scripts\python.exe' -B verify/ui-nav-20261122/r1/check_integrated_wireframe.py
~~~

ブラウザの「デザイン」設定でページズーム 100%／125%／200% を変更し、対象ページの実効 CSS ビューポートと `devicePixelRatio` を確認した。125% の OS スケーリングに相当するレイアウトを Chromium で再現した。実際の Windows 拡大率と Native の計測は製品工程で行う。起動するブラウザのプロファイルは S: 内の試験専用。HTML からの外部通信は CSP と Playwright の拒否ルートで遮断した。

## 実行と修正の証拠

- RED（終了コード 1）。マージ直後の旧ワイヤーフレームで `AssertionError: Missing the integrated production DB warning` を確認。
- 途中の再計測で、バッジがボタン枠を越え、200% で長文・停止・失敗を重ねたとき展開フィルターが一覧を押し出した。バッジを枠内に移し、短い状態行と低いビューポートでのフィルター内スクロールを採用。表示枚数は、実際に一覧のクリップ内に入る画像を数えるようにした。
- 主ナビの色・書体と Material アイコンは製品候補で再計測する。ワイヤーフレームは合成カードと学習画像を同じシェルに表示する。原監査分母は別途維持する。
