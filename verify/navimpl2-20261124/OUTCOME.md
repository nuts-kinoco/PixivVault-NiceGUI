## 変更

- おすすめの表示設定を主操作と同じ行に置き、候補のない棚の並べ替え・折りたたみ操作を設定内に集めた。読込結果と棚の説明を一行にし、長い通知はマウスまたはキーボードで全文を確認できる。カードの見た目を使いながら一覧の先頭までの高さを減らした。
- 最上段の本番 DB 警告を 28 CSS px の常設要約とし、「詳細」で保存先と警告の全文を表示した。自動処理の件数と内訳をヘッダー操作行に並べ、発生・解消の読み上げを既存の状態通知で行う。取得停止と回復の操作は既存の経路を使う。
- 重複整理の補助操作と説明を「絞り込み・注意事項」にまとめ、旧保存領域を含む旨と現在のスキャン結果を表示した。高さ 420 CSS px 以下の狭幅で一覧の既存カードを小さく配置し、作品画像が全体表示される行数を確保した。
- 通信棚卸しでは、おすすめの内部画像参照とヘッダーの明示クリックの 2 箇所で周辺コードの指紋が変わった。元の式の指紋と分類を照合し、台帳を更新した。[棚卸し台帳](../../tools/p6_network_review.json)
