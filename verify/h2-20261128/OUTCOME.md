## 1. 原受入の達否

| 単位 | 隔離試験で確認した結果 |
|---|---|
| 1. 局所・共有の 401 復帰 | 局所のみ・共有のみ・双方の 401 から明示確認で復帰した。認証確認はホームと本人 API の GET 各 1 回まで。確認中に別プロセスの取得を拒否し、失敗・中断・プロセス終了で共有が先に開かないことを確認した。403・429・結果不明の送信中記録と旧保存元の停止を保持した。 |
| 2. 設定画面への接続 | 既存ボタン 1 回で選択した Cookie を保存し、同一アカウントの稼働中リーダーと、保存済みフォロー台帳がある場合の定期取得待機に反映した。同一パスの旧 Cookie を保持するリーダーと共有専用の既存 POST を拒否した。起動時・自動取込の認証経路は 401 を解除せず、別アカウントの確認を表示した。 |

## 2. 状態の移り方

| 開始条件・発生事象 | 通信と永続状態 |
|---|---|
| 局所のみの 401、共有のみの 401、双方の 401 | 所有・来歴・旧保存元・送信中記録を検査。開いている側に 401 を記録してから、選択した Cookie で既存の本人確認に入る。 |
| 既知の 401、本人確認不成立、Cookie 不備 | 401 を保持する。追加の再送はない。既知の 401 の送信中記録は、応答・停止の保存と後処理を確認できた同じ送信だけが完了させる。 |
| 既存の 403・429、または確認 GET の応答が 403・429 | 既存停止なら送信しない。確認中の応答なら打ち切り、共有、局所の順に該当ステータスを記録する。 |
| 以前から結果不明の送信中記録が存在 | 局所や共有の 401 と同居していても送信しない。記録を保持する。 |
| 確認成功 | Cookie の選択を保存し、旧世代の送信を拒否する状態を確保する。同一アカウントの既存リーダーを安全に更新できる場合は認証済み世代に切り替える。局所を開き、途中終了に備えて共有は最後に開く。 |
| 保存後・共有解除前に中断、または共有解除に失敗 | 確認済み Cookie の保存が済んでいる場合がある。局所だけ開いている間も、共有 401 が一般通信を拒否する。再確認はその時点の状態から行う。共有の確定処理に入った後の中断要求では、確定結果を待つ。 |
| 復帰後に別プロファイルの旧 401 に遭遇 | そのプロファイルの局所停止を維持する。復帰済みの共有は再停止しない。 |

現行ゲートは復帰や 401 からの終端停止への移行で保存形式を更新し、世代を進める。旧保存元の不変読取りは従来の形式と revision 0・1 の厳密検査を用いる。P6 通信台帳は差分で変わった既存 15 箇所と新設 3 箇所の経路・根拠を更新した。全 312 箇所を照合した。
