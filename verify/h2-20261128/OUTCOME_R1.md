## 2. 送信中記録の状態と操作

| 確認できた事実 | 停止と次の操作 |
|---|---|
| HTTP 送信前に拒否・取消・失敗した、または確定応答を確認し後処理が成立した | その送信の記録を完了する。本人確認が失敗した場合は 401 を保持し、設定画面から再確認できる。 |
| 送信した可能性があり、処理の終了時に最終応答を観測できなかった | 記録を保持し、通常取得・同じ確認の再送・別の認証確認を拒否する。「取得停止の確認・回復」の明示承認で記録を退避できる。401 は維持し、復帰には設定画面で別途本人確認が必要。103 だけの応答もここに入る。 |
| 403・429、または終端停止の保存に失敗 | 共有への保存を試み、失敗時は局所への保存を試みる。判定前の記録を保持するので、両方の書込みが失敗していても退避から取得を再開できない。 |
| 途中終了・不完全な記録・401 と同居する判定根拠のない旧形式記録 | 停止と記録を維持する。既存の所有・履歴確認が必要。 |
| 本人確認成功 | Cookie 保存、局所の更新、共有の更新の順。同一アカウントへ反映できるリーダーは切り替え、反映できない場合は再起動を案内する。 |
