# 第 13 回 取得の中止通知の縮小版

| 経路 | 現行 | 縮小版と検証 |
| --- | --- | --- |
| 背景観測の正常判定、busy の期限、連続二回の一致 | 固定通知の解除、競合通知の削除 | 検出・固定のみ。正常観測と時刻経過で同じ通知が残る |
| 観測の選択証明、取得時の SQL 成功証明、選択世代 | 自動解除の根拠 | 解除判定から除く。物理 SQL 拒否は明示再確認の実取得経路で再現する |
| 通常 GET 成功、長い GET 中の観測 | 自動解除証拠の更新、busy による証拠消失 | 自動解除を廃止。通常 GET 成功も背景観測も固定通知を保持（Dots M、Argon M2） |
| 永続 STOP の停止元の縮小 | 二回一致で確定 | 背景観測は停止元を追加できる。縮小は明示再確認の成功による解除まで行わない |
| 新しい STOP・結果不明・保存異常・競合 | 当該周期に表示、競合は期限あり | 当該周期に固定し、背景観測は継続する |
| 通常の中止、429 待機、429 ラッチ、ヘッダー、既読 | 時刻・停止原因・通知 ID に従う | 既存の表示と寿命を維持 |
| 明示再確認の共有番兵 | 親の簡易検査 | 実取得と同じ作成・書込み・同期・除去。送信なし（Sol M1） |
| 明示再確認中の保存済み参照の拒否、公開前の並行拒否 | 一部の観測および通知を公開する時点で世代を更新 | 実取得の拒否成立時点から解除まで競合を検出。観測が判明させた拒否も保持（Dots H、Sol M2） |
| 明示再確認のゲート交換 | 旧物理 ID と一致が必要 | 正式に登録された現行経路で成功すれば旧通知を解除（Sol M3） |
| 明示再確認ボタン | 利用不能な固定通知にも表示 | 確認できる経路がある場合に表示。429 ラッチ・再確認できない資源終了異常のみなら説明（Dots L） |
| 同一経路の複数リーダー | 最後の一件で上書き | 稼働中のリーダーを選べる（Argon M1） |
| 保存 Cookie がない設定画面の Draft | 保存済みリーダーしか再構築できない | Draft の取得経路を使う（Argon L1） |
| 共有未設定の CDN | 由来なしでローカルの成功が効く | 共有経路の拒否として保持し、ローカルでは解除しない（Argon L2） |
| Dots M02 | 基点の既存制約 | 送信後から応答開始までの失敗の扱いを維持 |


## 解除範囲と並行処理

| 状態 | 記録または解除の境界 |
| --- | --- |
| 通常取得と物理 R/W SQL | 物理 R/W の失敗は観測の診断にも使う。解除は、明示確認が同じ物理 R/W 検査を完走した場合に限る |
| 取得側の拒否 | ゲートの型付き拒否、Native のリーダー作成前の拒否、永続 STOP 応答を知った時点で拒否世代を進める。通知を集約する前から再確認を止める |
| 429 | 既存の送信前の停止世代照合と保護区間内のラッチを使う。明示確認はラッチ済みの停止を解除しない |
| 明示確認中の観測 | その確認自身が作った競合を抑える対象は、明示確認が実際にバイトロックを取得したゲートに限定する。別ゲートの競合と、判明済みの STOP・結果不明・保存異常は反映する |
| Native の必須確認 | 現行のプロファイル・起動リビジョンを認証入口で照合する。保存済みと Draft の経路を分け、Draft には保存 Cookie を要求しない |
| 再確認の対象 | 取得由来は local/shared の組と保存選択の要否、観測由来はその異常を返した物理所有元で照合する。設定で選択を更新した場合は、現在の保存済み参照に通る経路を用いる |
| 正式なゲート交換 | 旧リーダーを閉じてから後継を明示登録するか、Native のゲート再登録で置換する。通知を保持したまま対象を移す。別々に稼働するゲートの証拠は合算しない |
| 未設定公開 CDN | 共有側の通知。許可経路を持たないため、別のローカル／共有リーダーの再確認で解除できない |
| 未確認の終了処理 | 同じ物理ゲートの正常な別リーダーの成功に関係なく、閉鎖確認不能の通知を保持する |
| 同じ操作で複数経路を再確認 | 後続の経路で物理ゲートの拒否が判明した場合は、そのゲートを含む先行判定を無効にする |
