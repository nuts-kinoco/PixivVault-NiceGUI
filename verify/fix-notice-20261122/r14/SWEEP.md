# 第14回 取得停止通知の棚卸し

| 拒否・異常が成立する地点 | 拒否世代 | 通知 | 監視 |
| --- | --- | --- | --- |
| GET／CDN のゲート入口（所有・参照・従来履歴、プロセス／バイトロック、R/W SQL、共有番兵） | 拒否が型付きになる時点で該当物理ゲートを進める | 取得側の既存通知に記録 | 固定通知で開始 |
| ゲート保護区間内での 401／403／終端 429 と終了失敗 | 永続 STOP と終了異常を成立点で記録。終端 429 は既存の停止確定も維持 | 既存の主結果と終了異常を記録 | 固定通知で開始 |
| Native 認証とフォロー同期の登録前許可確認（プロファイル、所有、ロック、R/W SQL、共有番兵） | 実ゲートの拒否は登録前でも同じ物理世代。物理ゲート外の検査はその所有元に帰属 | 事前確認の型付き拒否も記録 | 登録歴がなくても開始 |
| CDN の共有設定なし、HTTPS 所有プール終了確認不能 | 実在する経路に属する拒否は該当世代へ。未設定には架空の物理 ID を割り当てない | 既存の拒否・終了異常を保持 | 固定通知で開始 |
| 明示再確認の判明済み STOP・結果不明・保存異常・終了異常 | 同じ実ゲートを通る。同一操作で得た停止と終了異常も集約 | 再確認不能な終了異常は固定して表示 | 初回記録から開始 |
| 背景観測（成功、競合、STOP、結果不明、保存異常） | 取得拒否とは独立して観測結果を整合させる | 新規異常を検出周期内に固定。実際に再確認が持つロックによる競合は除外 | 観測自体は非侵襲 |
| 通常の中止・待機、期限、成功 GET | 既存の停止・送信フェンスを維持 | 固定通知の解除には使わない | 既存どおり |

| 明示再確認の入力 | 集約 |
| --- | --- |
| 同じ経路の稼働中リーダー複数、閉鎖済みの兄弟 | 稼働中の候補を全て評価。閉鎖済みは候補から除外 |
| 同じ物理ゲートを使う別ポリシー、登録前の拒否 | 開始時と解除直前の物理ゲート世代を照合 |
| 同じポリシーで状態ロック取得中の実拒否 | 状態ロックと独立した拒否記録をコミット直前にも照合 |
| 正常な再確認を別ポリシーが観測 | 同じ実ロックの再確認所有を認識。別ゲートの競合は表示 |
| 複数リーダーで成功と再確認不能な終了異常 | 全結果を集約し、固定通知と再確認不能理由を保持 |
| 別物理ゲート、正式なゲート交換 | 物理 ID で区別。正式交換後は現行経路で再確認 |


## 追加で突き合わせた境界

| 組み合わせ | 照合結果 |
| --- | --- |
| DB・ロックを別インスタンスで開いた CDN、登録前のフォロー同期 | 同じ物理キー。フォロー同期の通知公開を保留しても元の固定通知が残る |
| 既知のローカル STOP を共有ゲートに転記 | 転記先は新しい STOP を確定できる時点で世代を進める |
| HTTPS プール終了異常が通常取得の最外入口で判明 | ポリシーへ入る前に、取得経路の物理世代を進める |
| 実際の競合を観測したあとに別ポリシーの再確認が始まる | 競合を残す。取得した同じハンドルをプローブの前後で照合する |
| 再確認の解放直後に別のハンドルがロック | 以前の所有情報は解放の前に退役し、後続の競合は表示する |
| Native 初回に所有元なし、その後に正式登録 | 既存通知も追従する。新しい実経路で明示再確認して解除 |
| メモリ世代への並行書込み | 同じ物理ファイルペアへの加算を全て保持。別物理ゲートに伝播させない |

観測の競合判定は、ロックプローブの前後で同じ確認所有権を観測できた場合だけ、明示再確認自身へ帰属させる。OS が取得を返してからユーザー空間の追跡登録まで、および追跡を外してから解錠までの短い境界は、観測がロックを取らないため保守的に扱う。ここで競合表示の可能性は残る。既知の STOP、結果不明、実取得拒否の世代はこの除外対象に入らない。
