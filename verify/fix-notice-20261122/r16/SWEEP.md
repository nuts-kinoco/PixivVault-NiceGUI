# 第16回 取得停止通知・縮小版

| 確認候補 | 構成と選定 |
| --- | --- |
| 通常 GET・公開 CDN・フォローの登録済みリーダー | 現在のポリシーで稼働中かつ対象の物理ゲートに一致。選ばれた全候補の成功が必要 |
| Native Draft | Native が稼働中で必須所有元を構成済み。Draft およびゲート自体の観測通知に使う |
| Native 保存済み経路 | 保存済み選択の検査を要求する通知で選ぶ。ゲート自体の観測通知に未構成の保存済み経路を加えない |
| 未登録・閉鎖済み・必須ゲート未構成 | 候補外。候補がなければ解除せず、再確認できる取得経路がないと表示 |

| 観測の境界 | 世代と表示 |
| --- | --- |
| 再確認と別の物理ゲート | 同じポリシーでも同じ周期に反映 |
| 再確認と同じ物理ゲート | 開始・終了の重なりで競合由来のサンプルを捨てる |
| 再確認と同じゲートで確定済みの永続 STOP | STOP と帰属は同じ周期に反映。重なりから生じた番兵・競合の見かけは反映しない |
| 観測中の別経路からの拒否公開 | 現在の結果を反映し、再観測を1回予約する |
| 正式なゲート交換・リーダー変更 | 既存の構成世代を使い、旧構成の結果をフェンスする |

| 拒否の発生点 | 世代を記録する境界 |
| --- | --- |
| バイトロック、SQLite、所有マーカー、番兵、解錠、終了処理 | 捕捉済み OS 異常は変換前。I/O 進行中の解除を保留 |
| Native 選択、フォロー、共有所有確認、旧履歴 | 既存の共通の物理ゲート拒否記録を維持 |
| 公開 CDN の HTTPS 所有異常 | 所有検査の開始から結果を確定するまでをフェンスし、失敗確定時に型付き例外・通知より前に共有の物理世代を進める |
| 公開 CDN のアイドル期限処理 | 公開 CDN がバインドした共有ゲートをタイマーに引き継ぎ、次の GET 入口より前に終了異常を記録 |
| 再確認自身の HTTPS 所有異常 | 同じ検査と拒否記録を通す。理由を通知し、取得許可は出さない |
| 背景観測、未構成の所有元 | 実取得の拒否世代と混同しない。物理 ID がなければ架空の世代を作らない |
