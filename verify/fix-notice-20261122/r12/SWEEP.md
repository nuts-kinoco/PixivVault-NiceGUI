# 第12回 通知解除とリーダーのバインディング

基点は記録 6182ec76、同一コードの候補 f74c6656。観測と明示再確認を分ける。明示再確認は実際の取得許可経路を使い、ネットワークへ送信しない。監視は従来の無ロック経路で新規異常を同周期に表示する。

| トランスポート種別 | 基点でのゲートバインディング | Cookie 採用 | 設定変更 | ゲート交換 |
| --- | --- | --- | --- | --- |
| ManagedNetworkStopTransport（厳密 Live・ManagedLive） | なし | 選択を所有しない | 実際のゲート識別を共通登録 | 新ゲートで解除回数・縮小候補をリセット |
| _ProfileBoundTransport | local と選択 | 採用後に各登録済みリーダーを共通入口で更新 | 保存済み選択の新世代 | 同上 |
| SharedProfileStopTransport | local・shared と選択 | 同上 | 同上。Draft と同じ保存選択を追う | 同上 |
| _DraftAuthSharedTransport | なし | 自動採用の対象外 | Draft のパスそのものと保存済み選択を区別し、保存選択の世代を通知に反映 | 同上 |
| _SealedOwnerTransport（CLI・Public CDN） | なし | 選択を所有しない | shared 所有元を共通登録 | 同上。local を持つ別リーダーの選択世代とは分ける |
| 非ゲート Live / Public CDN・テスト注入 | 対象外 | 登録された Cookie 更新だけを継続 | 取得許可証拠を付けない | ゲートなしで通知を解除しない |

| 解除証拠 | 作用 |
| --- | --- |
| 明示再確認で現行リーダーの所有確認・選択・歴史・ゲート・終了確認が成功 | 元の取得経路全体と同じ物理 DB・ロックに関係する通知を解除。観測の選択証明や回数は使わない。shared 専用リーダーの成功は dual 経路の成功に代えない |
| STOP・共有の番兵・番兵の作成権限・現在の所有・SQL・閉鎖・429 ラッチが拒否 | 通知を保持。未確認の HTTPS 後処理には、同じゲートを使う別プールの成功を使わない。表示を閉じる操作による確認済みと区別 |
| 再確認中に別の拒否が届く | 実取得からの再発、同じ通知にまとまる新しい STOP／番兵、物理 R/W の開閉・実 SQL 拒否記録・番兵作成権限の実測拒否、バインディングや設定変更による不一致は保持。観測専用の immutable SQL 異常や単なる食い違いは実許可の代用にしない |
| 指紋採取が失敗 | 実拒否の証拠を保持したまま、欠測と同じ既存の `verify_fingerprint` 再確認段階を通す。反対側の再発確認を飛ばさない |
| バックグラウンド観測のみ正常 | 稼働リーダーの固定通知を解除しない。実取得側の成功後には従来の観測で解除可能。監視中の新規異常は同一周期に表示 |
| 物理 R/W SQL の拒否 | 第11回の実取得側の復旧証拠を維持 |
| Dots M02 | 基点からの既存制約。新規接続の送信後・応答前の再試行と番兵条件を変更しない |
