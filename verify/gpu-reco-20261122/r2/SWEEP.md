# おすすめの保護状態の棚卸し

対象は基点取り込み後の `006932a`。同じ保護集合が、ビューアを閉じる通常操作と開いたままの更新に使われていた。

| 経路 | 保護の所有者と解除 | 次の描画で維持する対象 |
| --- | --- | --- |
| 通常再読込、更新、設定変更、展開、畳む、カード寸法 | `render(preserve_viewer=False)` → `close_viewer` → `_viewer_closed` が選択と遅延オープンを解除 | 閉じた後も進行中の保存と理由入力 |
| ビューア内の非表示後、明示的な保持付き再読込 | `_queue_refresh(preserve_viewer=True)`。選択ピンはビューアの終了まで保持 | フィルター後にも同じ表示グループに残る選択 |
| 開く処理中 | `_opening` はリクエスト世代・画面世代・メディアで照合し、finally と閉鎖で解除 | 同じ操作がまだ有効な間だけ |
| 保存中 | `save_work` が `_saving` を設定し finally で解除 | 作品が候補集合に残る間の直前の位置 |
| 理由ダイアログ | `_pending_hide` は選択・タブ離脱・画面終了で解除。操作用トークンは再描画世代で失効 | 入力中の作品が候補集合に残る間の直前の位置 |
| OFF への切替 | 設定側は次の描画で読み取る | 実際に続いている操作の位置だけ。そのほかは元順 |
| ON 中の画像欠損・別節変更 | 設定、モデル世代、アカウントと保持画像の来歴を独立に照合 | 有効な保持画像で、実際に続いている操作の位置だけ |
| Undo、モデル不一致、GPU 失敗、カタログ／リーダー切替、画面終了 | 発行直前の世代・接続・ソース確認、または画面の終了処理で失効 | 現行の候補集合と元順へ戻す |

キャッシュの追い出しと権限失効は別条件。前者では保持画像を使用でき、後者では当該バイト列の公開と可用性の記録を禁止する。
