## 逸脱と回収

依頼中のパス表記に改行があったため、レビューは同じ tmp ディレクトリの `rv_cardgrid.md` を UTF-8 で確認。最初の基点再現は conftest による候補ソース挿入が判明したため、基点ソースとテストを同じ隔離ルートに置いて再実行した。処理終了の確認では PowerShell の JSON 配列展開を修正して PID を個別照合した。上の証拠は再実行分。実際の失敗画像の分布やネットワーク残差は隔離試験から推定しない。

次の承認済み作業は監督によるレビュー指摘・原受入との照合と、メディア pin／別名寿命の独立検証。実 API は今回の範囲外。
