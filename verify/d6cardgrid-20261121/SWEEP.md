# D6 一覧カード棚卸し

基点 `f2048fd0dfb7216d4c4cd1bbfd2405fecc440b32`。NiceGUI 3.18.0。 `sweep.py` は実際の世間ランキングの各カードと `descendants()` を合計する。青ハートなし **26 要素、12 リスナー**、あり **28 要素、12 リスナー**。外枠・エラースロット・メニューの子を含み、Vue が内部で作る DOM は含めない。ほかの要素数は分岐により変動するので下表ではソース上の主な構成を記した。

| 生成箇所 | 構造・イベント | 識別子とフォーカス | 表示順・特殊条件 |
| --- | --- | --- | --- |
| 基本 GalleryView | 順位、画像＋4 要素の失敗スロット、作品名、作者名。クリックと Enter、作者を開く右クリック | `data-work-id`、`gallery-author-open`、ビューアから直前要素へ | 検索順と末尾の「もっと見る」 |
| 世間 RankingView | 標準カード。好みタグの青ハート。右クリックと ContextMenu／Shift+F10。ブクマ・DL キュー・非表示・作者優先・Pixiv | `ranking-heart-*`、`ranking-ctx-*`、前のカードへフォーカス | 公式／評価／閲覧／伸びしろ。検索は提供順。条件不一致時に旧一覧を保持 |
| PersonalRankingView | 同じ5項目、青ハートなし。条件変更・保存設定と取得結果の寿命が別 | 世間と同じ | スコア・絞り込み。旧結果保持。合計と末尾セル |
| AuthorBrowseView（ライブラリ・おすすめ等のオーバーレイ） | 標準カード。おすすめ出所のメニューは別。画像なしの静的カードは6要素（非フォーカス） | `data-work-id`、作者とエポック、再表示時のスクロール維持 | 読取結果順・検索・追加。欠けたプレビューも残す |
| BookmarkView | 枠、画像オープナー＋失敗スロット、選択チェック、題名・作者、条件付き `DL済み`・★件数、作者／類似メニュー。クリック・Enter・変更。 | `bookmark-card/open/select/downloaded/card-count`。クリックと選択を分離。非対応作品の無効状態 | 絞り込みと表示順。選択は表示外にも保持。セッション照合 |
| LibraryView 作者 | カード、サムネ枠、オープナーと失敗スロット、作者外部リンク、作品数・閲覧数・容量、管理保存。右クリックに作者・類似・保存場所 | `data-author-id`・`data-representative-id`・`library-author-*`。復帰にオープナーの NiceGUI ID を使用 | 閲覧、保存日、容量等。検索・絞り込みで代表作品とグループを保つ |
| LibraryView ページ | カード、ページサムネ枠、外部・類似ボタン、追加ラベルと失敗スロット。クリック・Enter、子ボタンの伝播停止 | 作品 ID とページ番号、テスト ID、ビューアから同じページへ | 作者内の並び。複数ページと欠損管理。末尾セル |
| RecommendView | 棚・グループごとの作品カード、画像と失敗スロット、ブクマ・フォロー・非表示・作者登録・保存等。詳細な右クリックとキーボード | 棚・作品・表示世代。操作の寿命を表示世代に束縛 | グループ・棚順。作者やタグで続き。サービスにより可否が変動 |
| LearningView | 好意／否定の振り返り行、候補表示、出題、カード型概要。数・説明に加え画像や役割別操作 | 振り返り・出題・候補それぞれのテスト ID、セッション照合 | 好意／否定別の記録順、候補・出題は別の移動契約 |
| DuplicateView | 完全・近似・判定不能の比較グループ、対になる画像・候補、チェック、詳細・整理操作 | `duplicate-*-group` 等。確定は確認・保全処理と接続 | 容量や検出順を保ち、グループ内の残す／候補を区別 |
| ViewerBackupView | 作者単位バックアップカード、画像とオーバーレイの作者名、クリックと Enter | `backup-author-*`・`backup-open-*`、タブ移動可 | 直近バックアップ。画像は cover |
| ViewHistoryView／SimilarView | 閲覧履歴の行画像と開く操作、類似結果のサムネとスコア付きボタン | `view-history-row`／`similar-result`、結果世代 | 履歴順と類似度順。空画像あり |

`ui.card()` も検索し、設定・確認・停止回復・ダイアログ枠など単一 UI を一覧カード群と区別した。NiceGUI の `image.js` はマウント時に `setTimeout(0)` で URL を反映する。現行ランキングは更新ごとに UUID 付き pin を取得し、以前の pin を解放する。 `no-store` は残す。現在のルートが持つプロファイルの画像をブラウザーの通常 HTTP キャッシュに永続化せず、解放済みカタログの URL も再利用させない。
